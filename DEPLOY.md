# Build & Deploy

## Prerequisites

See `ENVIRONMENT.md`.

A modern web browser is sufficient.

## Build from source

No build process is required.

1. Extract the ZIP archive.
2. Open the `src` directory.
3. Launch `index.html` in a modern browser.

Output is produced directly by the browser.

## Deploy

### GitHub Pages

1. Push the repository to GitHub.
2. Open Repository Settings.
3. Navigate to Pages.
4. Deploy from the `main` branch and root folder.
5. Save changes.

### Alternative Hosting

Any static hosting service such as GitHub Pages, Netlify, Vercel, or a standard web server can be used.

## Verify

1. Open the application.
2. Confirm that the boot screen loads successfully.
3. Enter the game.
4. Open at least one module.
5. Verify that interactions, scoring, XP progression, and activity logs function correctly.

The application should load without requiring login, database configuration, or server setup.
