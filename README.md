# AlgoLab

AlgoLab is a browser-based educational game designed to teach algorithm analysis and Big-O complexity through interactive gameplay. Players act as an Algorithm Specialist tasked with restoring malfunctioning algorithm modules by solving challenges involving searching, sorting, complexity prediction, and optimization.

The game aims to improve students' understanding of algorithm efficiency by connecting theoretical complexity concepts with practical decision-making and visual feedback.

## Run it quickly

Open `src/index.html` in a modern web browser.

No installation is required.

For deployment options and hosting instructions, see `DEPLOY.md`.
